How to read these numbers

Global RMSD: C1′ atoms over all residues after a least-squares superposition (the same fit that is drawn here). US-align RMSD: from US-align's default, sequence-independent structural alignment over a best-fit subset of residues; residues it pairs are not necessarily the same sequence positions, so it is an optimistic measure. Ratio = global / US-align; a target is flagged when it is above 2. Deviation colors the distance between each predicted residue's C1′ and its reference counterpart (same sequence position). pLDDT is Boltz-2's own per-residue confidence (0 to 100).
