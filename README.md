# InspectRNA

Interactive 3D viewer and open repository of isolated viral regulatory RNA structures from the Protein Data Bank,
shown side by side with Boltz-2 predictions and RMSD / US-align / pLDDT metrics.

**Live viewer:** https://mirikrupkin.github.io/inspectrna/  (enable Settings -> Pages -> `main` / root)

## What is in this repository

```
index.html            the viewer (static page, no server needed)
viewer/               viewer-ready copies generated by the site-builder notebook (do not edit by hand)
data/pdb/             cleaned reference structures derived from PDB entries (ground truth)
data/boltz2/          Boltz-2 predictions, superposed onto the matching reference
data/metrics/         metrics.csv (one row per target) and the raw per-run result tables
```

## Data provenance

* `data/pdb/` holds cleaned experimental structures derived from Protein Data Bank entries: a model and chains were
  selected (the `copyA` / `chainAB` suffixes record which), then cleaned and renumbered. They are not the original entries.
* `data/boltz2/` holds Boltz-2 predictions superposed onto the matching `data/pdb/` structure so that both share a
  coordinate frame. Raw Boltz output is not included.
* `viewer/structures/` contains the same structures with hydrogens removed, residues renumbered 1..N, and the prediction
  re-fitted onto the reference by least squares on C1' atoms (the fit behind the global RMSD).

## Metrics

* **Global RMSD**: C1' atoms over all residues after least-squares superposition.
* **US-align RMSD**: US-align's default, sequence-independent structural alignment (`-mol RNA`) over its best-fit subset.
  Residues it pairs are not necessarily the same sequence positions, so this is an optimistic, local measure.
* **Ratio** = global / US-align; targets above 2 are flagged "LARGE GAP".
* **pLDDT**: Boltz-2's per-residue confidence (0 to 100); the table shows the mean on a 0 to 100 scale.
* Targets run more than once appear once, using the run whose stored structure reproduces the CSV values; other runs are listed.

## Run locally

```
python3 -m http.server
```
then open http://localhost:8000
